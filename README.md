# Abdulhadi's Portfolio

A personal portfolio website showcasing my journey as a Computer Science student, along with my projects, skills, and achievements. The website is completely handcrafted using HTML and CSS with a nature-inspired design centered around a tree representing my growth as a developer.

## About

This portfolio reflects my journey in Computer Science.

Instead of relying on templates or website builders, every section has been designed and developed from scratch. The website follows a nature-inspired theme where different parts of the tree represent different stages of my academic and programming journey.

## Design Philosophy

The portfolio follows a nature-inspired theme.

The tree symbolizes continuous learning, while each section represents a different stage of my growth as a programmer. Green tones, leaf elements, and wooden textures are used throughout the website to create a consistent visual identity.
